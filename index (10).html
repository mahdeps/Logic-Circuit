الجمل الشرطية

if · if-else · if-elif-else

if بالعربي معناها «إذا» — إذا تحقّق الشرط، نفّذ هالأمر. وهون بتبلش البرمجة الحقيقية 🧠

⚠️⚠️ إشيين حياة أو موت:

1️⃣ النقطتين : بآخر سطر الشرط — إجباري

2️⃣ المسافة البادئة (٤ مسافات) قبل الأمر — إجباري

بلغات ثانية بيستخدموا أقواس {}… بس بايثون بتعتمد على المسافة عشان تعرف مين جوّا الشرط ومين برّا.

✓ صح — الأمر جوّا الشرط
if age >= 18:
    print("بالغ")
print("انتهى")
✕ غلط — نسينا المسافة
if age >= 18:
print("بالغ")

01

زوجي ولا فردي؟ 🔢

برنامج يسأل المستخدم رقم، ويقلّه إذا كان زوجي ولا فردي. تلميح: استخدم %

⌄
even_odd.py
num = int(input("أدخل رقم: "))

if num % 2 == 0:
    print("الرقم زوجي ✅")
else:
    print("الرقم فردي 🔸")
02

الأكبر بين رقمين ⚖️

برنامج ياخد رقمين ويطبع الأكبر فيهم — وينتبه لحالة التساوي.

⌄
max_two.py
a = int(input("الرقم الأول: "))
b = int(input("الرقم الثاني: "))

if a > b:
    print("الأكبر هو:", a)
elif b > a:
    print("الأكبر هو:", b)
else:
    print("الرقمين متساويين ⚖️")
03

فاحص قوة كلمة السر 🔐

يقيّم قوّة كلمة السر حسب طولها: أقل من 6 ضعيفة، 6–9 متوسطة، 10+ قوية. تلميح: len()

⌄
pw_check.py
password = input("أدخل كلمة السر: ")
length = len(password)

if length < 6:
    print("ضعيفة ❌")
elif length < 10:
    print("متوسطة ⚠️")
else:
    print("قوية 💪")
04

الآلة الحاسبة 🧮

برنامج ياخد رقمين وعملية وينفّذها — مع حماية من القسمة على صفر.

⌄
calculator.py
a = float(input("الرقم الأول: "))
op = input("العملية (+ - * /): ")
b = float(input("الرقم الثاني: "))

if op == "+":
    print("الناتج:", a + b)
elif op == "-":
    print("الناتج:", a - b)
elif op == "*":
    print("الناتج:", a * b)
elif op == "/":
    if b == 0:
        print("ما بنقدر نقسم على صفر ❌")
    else:
        print("الناتج:", a / b)
else:
    print("عملية غير معروفة 🤷")

📌 لاحظ: حطينا if جوّا if — بيسمّوها شرط متداخل (Nested)، وحمينا البرنامج من القسمة على صفر 🛡️ هيك بيفكّر المبرمج الشاطر: بيتوقّع المشاكل قبل ما تصير.
